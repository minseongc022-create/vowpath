## 1) 이메일에서 IP만 찾기 (1분)

Contabo 메일에서 아래 비슷한 글자를 찾으세요.

- `IP address` / `IPv4` / `Server IP`
- 예: `161.97.xxx.xxx` 처럼 **숫자.숫자.숫자.숫자**

그 **IP만** 이 채팅에 붙여넣기.  
(비밀번호·root password 는 넣지 마세요.)

---

## 2) 그다음 (제가 IP 받은 뒤 안내)

맥/윈도우 **터미널**을 열고, 제가 주는 **한 줄**만 복사→붙여넣기→엔터.

비밀번호는 터미널이 물어볼 때 **이메일 비밀번호를 직접 타이핑**하면 됩니다.  
화면에는 안 보여도 정상입니다.

설치가 끝나면 `.env` 도 **짧은 질문 몇 개**로 채우게 해 두었습니다.
