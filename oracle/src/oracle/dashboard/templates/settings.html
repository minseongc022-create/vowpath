오늘 실전 체크리스트

  1. Alpaca 계정 생성 (paper 먼저)
  2. oracle/.env에 API 키 입력
  3. 이 화면에서 브로커 연결 확인
  4. 홈 → 매매 계획 → 거래에서 한 건만 승인
  5. 실거래는 ORACLE_LIVE_TRADING=1 후에만
# oracle/.env 예시
ORACLE_BROKER=alpaca
ALPACA_API_KEY=...
ALPACA_SECRET_KEY=...
ALPACA_PAPER=1
# ORACLE_LIVE_TRADING=0   ← 기본 유지 권장
