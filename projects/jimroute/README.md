# 짐루트 (JimRoute)

한국 **소형 이사·용달 업체**를 위한 버티컬 SaaS MVP.

> 견적 → 카톡 링크 공유 → 계약 확정 → 배차 → 고객 실시간 안내

## 왜 이 업종인가

| 경쟁 | 문제 |
|------|------|
| 엑셀 + 카카오톡 | 견적 실수, 배차 누락, 고객 불안 |
| Shifton 등 해외 FSM | 한국 이사 용어·평수·사다리차 미지원, 달러 결제 |
| 플러그/싸인플로 | 견적서만 됨. 배차·기사·고객안내 없음 |
| 다이사 등 비교 플랫폼 | 고객용. 업체 운영툴 아님 |

**짐루트 포지션:** 한국 이사업체 전용, 5개 기능만 끝까지 잘함.

## 실행

```bash
cd projects/jimroute
npm install
npm run dev
```

http://localhost:3000

## 화면

| 경로 | 설명 |
|------|------|
| `/` | 랜딩 |
| `/dashboard` | 사장님 대시보드 |
| `/dashboard/quotes/new` | 견적 생성 (평수·거리·엘리베이터 자동 계산) |
| `/dashboard/jobs` | 작업 목록 |
| `/dashboard/dispatch` | 팀 배차 |
| `/q/[id]` | 고객용 견적서 (카톡 링크 공유) |
| `/track/[id]` | 고객용 이사 진행상황 |
| `/track/[id]?owner=1` | 사장님용 상태 업데이트 |

## 수익 모델

- **월 29,900원** (1~3인 소형 이사업체)
- **월 49,900원** (팀 2개 이상, 기사앱 포함 — v2)
- 고객 **40곳** × 29,900원 ≈ **월 120만 원 매출**
- 고객 **35곳** × 49,900원 ≈ **월 175만 원** + 초기 세팅비

목표: **고객 30~40곳**이면 월 순수익 1,000만 원 (인건비 1명 기준)

## 기술 스택

- Next.js 15, TypeScript, Tailwind CSS v4
- MVP: localStorage (프로덕션: Supabase + 카카오 알림톡)
