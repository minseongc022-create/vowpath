# 짐루트 90일 실행 로드맵

**목표:** 한국 소형 이사업체 10곳 유료 파일럿 → 30곳 → 월 순수익 1,000만 원

**초기 자본:** 20~30만 원  
**월 구독료:** 29,900원 (Starter) / 49,900원 (Pro)

---

## 왜 이사업체인가 (경쟁사가 형편없는 이유)

### 1. 진짜 경쟁은 "엑셀 + 카톡"
- 한국 이사업체 80% 이상이 견적을 엑셀/수기로 작성
- 배차는 단톡방, 고객 안내는 전화
- **소프트웨어 경쟁이 아니라 습관 경쟁**

### 2. 있는 툴들은 맞지 않음
| 제품 | 왜 대장 못 하는가 |
|------|------------------|
| Shifton | 해외 FSM, 한국어/평수/사다리차/반포장 옵션 없음 |
| 플러그/싸인플로 | B2B 견적 일반. 배차·기사·이사 특화 없음 |
| 이디스/인사비 | 인테리어용. 이사 업체 UX 아님 |
| 다이사/이사견적비교 | 고객용 리드. 업체 운영툴 아님 |

### 3. 짐루트가 이기는 방법
- **한 업종만** (소형 이사·용달, 직원 3~15명)
- **5개 기능만** 끝까지: 견적 / 링크공유 / 계약 / 배차 / 고객안내
- **한국 이사 용어** 내장: 평수, 포장/반포장, 사다리차, 계단비
- **모바일 퍼스트** (사장님·기사·고객 모두 폰으로)

---

## Phase 1: 검증 (Day 1~30) — 비용 ~15만 원

### Week 1: 업종 고정 + 인터뷰 10곳
- 타겟: 서울·경기 **소형 이사업체** (1팀~3팀, 연매출 3~15억)
- 찾는 법: 네이버 "○○구 이사" 검색 → 전화 → "사장님 15분만요"
- 질문 3개만:
  1. 견적 내는 데 몇 분 걸려요?
  2. 배차 실수로 고객 컴플레인 난 적 있어요?
  3. 고객이 '지금 어디쯤?' 전화 몇 번 와요?

### Week 2~3: MVP 완성 (이 레포)
- 견적 자동 계산
- 고객 링크 (카톡 공유)
- 배차 보드
- 고객 진행상황 페이지

### Week 4: 유료 파일럿 3곳
- 가격: **월 9,900원** (3개월 고정, 피드백 의무)
- 조건: 매주 30분 통화, 실제 이사 2건 이상 사용
- 영업 멘트:
  > "견적서 카톡으로 보내고, 고객이 '지금 어디?' 전화 안 오게 하는 거예요.  
  > 한 달 9,900원, 안 되면 그만."

**Phase 1 성공 기준:** 3곳 중 2곳이 "다음 달도 쓸게요"

---

## Phase 2: 제품-시장 적합 (Day 31~60) — 비용 ~10만 원

### 제품
- [ ] 카카오 알림톡 (견적 링크 자동 발송)
- [ ] 토스페이먼츠 계약금 링크
- [ ] 기사용 모바일 페이지 (배정 확인, 완료 체크)
- [ ] 견적 단가표 커스터마이즈 (업체별 평당 단가)

### 영업
- 파일럿 3곳 레퍼런스로 **같은 구 이사업체 10곳** 콜드콜
- 이사업 카페/밴드에 "우리 업체 견적 이렇게 보냄" 스크린샷
- 단가 **19,900원**으로 인상 (파일럿 종료)

### 운영
- 온보딩 30분 (화면공유로 첫 견적 같이 만듦)
- 주 1회 "이번 주 이사 몇 건?" 체크인

**Phase 2 성공 기준:** 유료 고객 10곳, 이탈 2곳 이하

## Phase 3: 스케일 (Day 61~90) — 비용 ~5만 원

### 가격
| 플랜 | 가격 | 대상 |
|------|------|------|
| Starter | 29,900원/월 | 1팀, 견적+배차+고객안내 |
| Pro | 49,900원/월 | 2팀+, 기사앱, 알림톡 무제한 |

### 영업 채널 (돈 안 드는 것부터)
1. **지역 밀도:** 강남 5곳 → 송파 5곳 → 분당 5곳 (입소문)
2. **이사업체 단톡방/협회** 소개
3. **네이버 블로그:** "이사업체 견적 자동화 후기" (고객 사례)
4. **유튜브 쇼츠:** "사장님 카톡 지옥 탈출" 30초

### 수익 시뮬레이션 (Day 90 목표)

| | 수량 | 단가 | 월 매출 |
|--|------|------|---------|
| Starter | 25곳 | 29,900 | 747,500 |
| Pro | 10곳 | 49,900 | 499,000 |
| **합계** | **35곳** | | **1,246,500** |

비용: 서버 5만 + 알림톡 10만 + 지원 파트타임 30만 = **45만**  
**순수익 ≈ 80만** (Day 90 시점)

→ **6개월차 목표 50곳**이면 순수익 1,000만 원 돌파
