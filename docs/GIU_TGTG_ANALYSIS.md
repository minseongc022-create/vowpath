# Too Good To Go vs Giu — compressed product

Giu is not a TGTG clone. Same job (surplus food → pay → pickup), tighter for HCMC + Korean founder ops.

## Giu loop (compressed)

1. **오늘 구출** — photo feed, district/category chips, golden-hour chip (19–21)
2. **박스** — photo → price → pickup grid → map → sticky pay
3. **티켓** — big code only; merchant confirms pickup
4. **즐겨찾기** — store ♡ → in-app alert when new box opens

## Why this is tighter than TGTG

- No surprise-only / swipe lock-in / impact dashboard clutter
- Escrow one-liner instead of long trust essays
- Embedded map + Zalo for VN reality
- KO/VI in one toggle; Lemon Squeezy for KR solo MoR

## Not copying

- Swipe-to-confirm native lock
- Global CVS density playbook
- Dense marketing first viewport
