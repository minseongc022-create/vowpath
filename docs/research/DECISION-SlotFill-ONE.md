# DECISION: 하나만 한다 — SlotFill

**확정일:** 2026-07-26  
**결정:** 다른 TOP 후보는 당분간 **하지 않는다.**  
**사업 하나:** **SlotFill** — 예약 확정 + 취소/노쇼 빈 슬롯 대기열 채우기 AI 직원  
**본진 국가:** **미국** (한국보다 유리). 상세 비교 → [`SlotFill-best-country.md`](./SlotFill-best-country.md). 한국은 학습용 소수 파일럿만.

---

## 1. 한 문장

사람이 매일 돈 받고 하는 “내일 예약 확정 전화/문자”와 “취소 나면 대기자 연락해서 자리 메우기”를 AI가 대신하고, 월 구독을 받는다.

대체 대상 = **프론트 데스크 / 리콜 담당의 반복 커뮤니케이션 시간**  
(진료·시술·결제 협상은 사람)

---

## 2. 왜 이것만인가 (다른 걸 버리는 이유)

| 후보 | 버리는 이유 |
|------|-------------|
| 인바운드 AI 전화(TOP2) | 시장 검증됨 but **경쟁 9/10**, 사고면적 큼. SlotFill 성공 후 업셀 |
| 견적 후속(TOP3) | 좋지만 ICP·채널이 홈서비스로 갈림. **지금은 한 ICP만** |
| 북키핑/AR/COI/도매 | 연동·신뢰·규제 비용이 솔로 1번에 무거움 |

SlotFill이 이긴 이유: **노쇼 = 현금 손실**이 사장님에게 자명하고, SMS+캘린더로 80%+ 가능, 경쟁이 풀 리셉션보다 좁다.

---

## 3. 사업 상세

### 3.1 누가 고객인가 (ICP — 좁게)

**1순위만 판다 (첫 90일):**
- **1인~3체어 독립 치과** (체인·DSO 제외)
- 또는 **미용실/네일/피부** (예약·노쇼 명확)
- front desk 1명 있거나, 원장/원장이 겸업
- 이미 “확정 문자/전화”를 **사람이 하고 있음**

**안 판다:**
- 노쇼가 거의 없는 곳
- Weave / Solutionreach 등을 이미 풀로 쓰는 곳
- 대기 손님(waitlist)이 없는 저수요 샵

### 3.2 제품이 하는 일 (사람이 하던 일 그대로)

1. 방문 **24~48시간 전** SMS로 확정 요청 (미응답 시 전화)
2. 고객이 취소하면 → **대기자 리스트에 자동 아웃바운드** (문자→전화)
3. 수락하면 캘린더에 넣고, 원장/데스크에 알림
4. 주간 리포트: 확정률, 메운 슬롯 수, 추정 회수 매출

### 3.3 안 하는 일 (범위 고정)

- 보험 조회, 청구, 임상 상담
- 인바운드 신규 콜 전체 응대 (나중 업셀)
- “마케팅 자동화” 포지션 (잡히면 가격이 $29로 죽음)

### 3.4 가격

| 플랜 | 월 | 포함 |
|------|-----|------|
| Starter | **$79 / ₩99,000** | SMS 확정 + 기본 waitlist |
| Growth | **$149 / ₩199,000** | 음성 확정 콜 + 우선 waitlist |
| Practice | **$249 / ₩329,000** | 멀티캘린더·리포트 |

음성은 **포함 콜 수 캡** 필수. 무제한 flat 금지.

**₩1,000만/월:** Growth 약 50~70 paying이면 도달 가능(환율·할인에 따라). 현실 목표 90일 = 유료 10, 180일 = 유료 50.

### 3.5 원가·마진

- 고정: 호스팅+도메인 ≈ 월 수만원~$30
- 변동: SMS/Voice 사용량 — Starter 목표 공헌 50%+, Growth는 콜 캡으로 40%+
- LLM은 짧은 대화만 → 소수 $

### 3.6 경쟁과 차별

| 기존 | 한계 |
|------|------|
| PMS 내장 리마인더 | 알림만, **대기열 채우기 약함** |
| 범용 문자 마케팅 | 예약 상태와 무관, 스팸 느낌 |
| AI 리셉션 | 인바운드 전쟁터, 비쌈 |

SlotFill 포지션: **“빈 자리를 돈으로 바꿔 주는 프론트 직원”**

### 3.7 실패하면 끝나는 기준 (2주)

- 인터뷰 20곳 중 “돈 낼 의향” 3 미만  
- 수동 대행 5샵에서 메운 슬롯 ≈ 0  
→ **이 사업 kill.** (그때만 TOP3 견적 후속 검토)

## 4. 업체에게 먼저 물어볼 곳 — 연락처·채널·스크립트

원칙: **광고 전에 사람이 하는 일인지, 얼마 쓰는지, 누구 번호로 연락할지**만 묻는다. 제품 자랑 금지.

### 4.A 한국 (먼저 여기 — 언어·접근성)

#### 어디를 노리나
| 업종 | 왜 |
|------|-----|
| **강남/분당/수원 등 독립 치과** (2~4체어) | 노쇼·리콜·확정 콜이 SOP |
| **미용실·네일·반영구** (예약제) | 의사결정 빠름, 도입 쉬움 |
| (후순위) 동물병원, PT | 동일 JTBD, 규제·톤만 다름 |

#### 연락처를 어디서 구하나
1. **네이버 지도 / 카카오맵**  
   - 검색: `치과`, `미용실`, `네일샵` + 지역  
   - 필터: 리뷰 50~500, **개인/소형** (네트워크 병원·대형 프랜차이즈 제외)  
   - 프로필의 **전화번호를 그대로** 사용 (대표 전화 = 프론트)
2. **네이버 플레이스** 영업시간·전화번호 복사 → 스프레드시트  
3. **인스타그램** 로컬 샵 — DM은 응답률 낮음. **프로필 전화/카톡 비즈니스** 우선  
4. **상가 밀집 상권 도보** — 명함 대신 “2주 무료 확정 대행” 한 장 (대면이 한국에서 강함)

#### 누구에게 말하나
| 직함 | 비고 |
|------|------|
| **원장 / 원장 배우자** | 최종 결제 |
| **실장 / 데스크 실장** | 실제 확정 콜 하는 사람 — **인터뷰 최적** |
| 피하기 | 네트워크 병원 본사, 콜센터 |

#### 한국 전화 오프닝 (20초)
> “안녕하세요, 갑자기 영업 전화 아닙니다.  
> 치과(미용실) 프론트에서 **예약 확정 전화/문자** 아직도 사람이 하시는지,  
> 그 일만 여쭤보려고 하는데요. 2분만 괜찮으실까요?”

거절 시: “문자로 질문 3개만 보내도 될까요?” → 아래 질문 SMS

#### 한국에서 물을 질문 (무조건 이 순서)
1. 예약 확정은 **누가**, **하루 몇 건**, **전화/문자 중 뭐**로 하나요?  
2. 지난달 **노쇼+당일취소** 대략 몇 건이었나요? (모르면 “체어 비는 날 주 몇 번?”)  
3. 취소 나면 **대기 손님**에게 지금 어떻게 연락하나요?  
4. 그 일에 쓰는 시간, 또는 알바/실장 인건비로 치면 월 얼마 같나요?  
5. 그 두 일(확정+대기열)만 **월 10~20만 원**에 대신하면 써볼 의향 있나요? (예/아니오/조건)

#### 한국 후속 채널
- 전화 연결되면 → **카카오톡 채널/오픈채팅**으로 2주 파일럿 제안  
- 파일럿: 캘린더(구글/네이버예약) 공유 또는 CSV → 우리가 **수동으로** 확정·대기열 대행  
- 성공 정의: 2주에 **메운 슬롯 ≥ 2** 또는 확정률 체감
