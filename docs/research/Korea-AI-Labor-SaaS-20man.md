## 전 재산(₩20만)을 넣는 단 하나

# **소형 세무·기장 사무소용 AI 자료요청 직원 (가칭 DocChase KR)**

> 사무원이 매달 하는 “자료 아직이세요?” 전화·카톡을, **수임 계약 이행용 정보성 알림톡**으로 대체한다.

### 1) 투자자
- 고객이 이미 **사무원 월급 ₩200만+**를 냄. 구독 ₩10–20만은 ROI 설명 가능.  
- 치과·학원과 달리 **소비자 SaaS 광고 전쟁**이 약함.  
- Clobe와 **정면경쟁이 아님**(수집 vs 독촉). 나중에 연동·업셀.

### 2) 창업자
- ₩20만 배분 **[추정]:** 솔라피 충전 ₩8만 + LLM ₩4만 + 도메인 ₩1.5만 + Cloudflare Paid 1–2개월 ₩1.5만 + 예비 ₩5만.  
- MVP: 스프레드시트 업로드 + 템플릿 + 스케줄러. EMR/차트 불필요.  
- 보이스·GHL급 설정 불필요.

### 3) 고객(세무사·사무장)
- 마감 전 독촉 지옥이 실재(구인·자동화 벤더 서사와 일치).  
- “직원 대신 독촉만”이면 도입 결정 낮음.

### 4) 경쟁
- Clobe = 인증서·자동수집(무겁고 강함).  
- DocChase = **가벼운 독촉 직원**. 소형이 Clobe 전에 사는 쐐기.

### 5) 기술
- Next on Cloudflare, Solapi API, 템플릿 심사 워크플로, 수신거부·발송 로그.  
- 해자: 업종별 템플릿 승인율·회수율 데이터. LLM 자체 아님.

### 수정 결론
- 이전에 말한 **미국형 QuoteChase 이메일/알림톡 드립은 한국에서 약하거나 위법 리스크**.  
- 한국+₩20만 기준 전 재산 배팅은 **세무 자료요청 AI(DocChase KR)**.  
- 반드시 먼저: (1) 알림톡 템플릿 3종 심사 통과 (2) 세무 사무소 5곳에 “독촉에 주 몇 시간?” 실측 (3) 유료 3곳.

## 2주 킬 기준

1. 템플릿 심사 **2회 반려**면 카피 전면 수정, 3회면 피벗(정비소 예약 AI).  
2. 파일럿 3곳에서 주 절감 **&lt;3시간**이면 킬.  
3. 유료 전환 0/5면 세일즈 문제 — 제품 키우지 말 것.

## Effiroad vs DocChase KR (이 레포 제품과 비교)

**Effiroad** = 미국 복구(restoration)·HVAC용 **AI 전화 접수 + 긴급 트리아지 + 크루 디스패치** SaaS (이 코드베이스).  
**DocChase KR** = 한국 소형 세무·기장용 **자료요청 독촉 AI 직원** (본 문서 권장안).

| 축 | Effiroad (지금 제품) | DocChase KR (한국·₩20만 권장) |
|----|----------------------|-------------------------------|
| **대체하는 유급 일** | 야간/미스콜 **answering service** + 오너/디스패처의 접수·크루 SMS | 세무 **사무원의 월간 자료 독촉** (전화·개인카톡) |
| **시장** | **미국** 홈서비스 SMB | **한국** 소형 세무·기장 |
| **채널** | Twilio **보이스 + SMS** | 솔라피 **알림톡**(정보성) |
| **ARPU** | Flex ~$69+사용 / Pro **$299**/mo / Scale $399 | ₩7.9–19.9만/월 (**~$60–150**) |
| **₩1,000만 필요 고객** | Pro급이면 **≈24–35곳** (환율·ARPU로 유리) | ₩12만 → **≈84곳**, ₩19.9만 → **≈51곳** |
| **초기비** | 보이스·번호·COGS·컴플라이언스 → **₩20만과 충돌** | 알림톡 충전+CF+도메인 → **₩20만 안에 설계됨** |
| **제품 복잡도** | 높음: Retell/Twilio, 트리아지, 오너 1/2, 크론 디스패치, 빌링 | 낮음: CSV+스케줄+템플릿+대시보드 |
| **경쟁** | OnCrew, ServiceAgent, Rosie/Upfirst, Jobber AI 등 | Clobe(수집)·CMS(결제) — **독촉-only는 쐐기** |
| **해자 후보** | 복구/HVAC **도메인 트리아지 + 디스패치 루프** | 업종 템플릿 승인율·회수율 데이터 |
| **한국 이식** | 보이스 원가·AI전화 경쟁(ClawOps 등)·₩20만 제약으로 **비추** (본 문서 STEP3) | 설계 자체가 한국 채널·법률 |

### 한 줄 판결

- **같은 JTBD가 아님.** Effiroad = “전화가 오면 접수·출동”, DocChase = “마감 전에 서류 달라고 쫓기”.  
- **Effiroad가 제품·ARPU·해자로는 더 큼.** 이미 빌드된 자산이고, 미국 복구 1건($8k급 마케팅 카피) 대비 구독 ROI 스토리가 강함.  
- **제약(한국 + ≤₩20만)만 보면 DocChase가 맞음.** Effiroad형 보이스 스택은 그 예산·시장으로는 검증 루프가 안 돌아감.  
- **병행은 비추.** 스택·ICP·세일즈 채널이 완전히 갈림. “Effiroad를 한국 세무용으로 피벗”도 비추 — 코어(보이스 디스패치)가 독촉 업무와 안 맞음.

### 창업자 선택 프레임

| 상황 | 선택 |
|------|------|
| 미국 restoration/HVAC에 계속 베팅 + 이미 코드·도메인 | **Effiroad 밀기** (본 연구의 한국·₩20만 필터 밖) |
| 전 재산 ≤₩20만 + **한국만** | **DocChase KR** (또는 킬 후 정비소 예약 AI) |
| Effiroad PMF 전인데 한국으로 “싼 재시작” | DocChase는 **새 제품**. Effiroad 코드 재사용 가치는 낮음(알림톡·세무 템플릿이 핵심) |

**사실:** Effiroad 포지셔닝·가격은 레포 `README.md`, `lib/constants.ts`, 마케팅 카피 기준. DocChase 매출·절감은 **미검증 산수**.
