# 수임체크 — 카카오 알림톡 (솔라피) 연동

실발송은 **Solapi**를 사용합니다. 키가 없으면 UI는 **연습 모드**로 동작하고, 현황판·제출·원탭 회신은 그대로 확인할 수 있습니다.

## 1. 솔라피·카카오 준비

1. [solapi.com](https://solapi.com) 가입 · API Key / API Secret 발급  
2. 발신번호 등록 (`SOLAPI_FROM`, 숫자만 `01012345678`)  
3. 카카오 비즈니스 채널 연동 → `pfId`  
4. 알림톡 템플릿 심사 (정보성 · 수임 계약 이행 안내)

### 권장 템플릿 본문 (변수명 그대로)

```
[#{사무소명}] #{월} 기장 자료 제출 안내

안녕하세요, #{상호} #{담당자}님.
기장 마감을 위해 아래 자료 제출을 부탁드립니다.

#{자료목록}

자료 올리기: #{제출링크}
이미 냈거나 해당 없으면: #{회신링크}

문의는 사무소로 연락 주세요.
#{사무소명}
```

심사 통과 후 `templateId`를 환경변수에 넣습니다.

## 2. 환경변수 (`apps/docchase/.env.local`)

```bash
SOLAPI_API_KEY=
SOLAPI_API_SECRET=
SOLAPI_FROM=01012345678
SOLAPI_PF_ID=KA01PF...
SOLAPI_TEMPLATE_ID=KA01TP...
# 선택: 알림톡 실패 시 SMS 대체 끄기
# SOLAPI_DISABLE_SMS=true
```

Vercel 등에도 동일 키를 넣습니다. Root Directory = `apps/docchase`.

## 3. 앱에서 켜기

1. `npm run dev` (또는 배포)  
2. 대시보드 → **설정** → 솔라피 상태가 “연동됨”인지 확인  
3. **실발송 켜기**  
4. 오늘 독촉에서 자료 요청 → 실제 알림톡

API:

- `GET /api/alimtalk/status`  
- `POST /api/alimtalk/send` `{ messages: [...] }`

## 4. 차별점과의 연결

알림톡만내면 클로브·문자툴과 비슷해집니다. 수임체크 쐐기는:

1. **제로앱 제출 링크** (`/s/...`)  
2. **원탭 회신** 이미냈어요 / 해당없음 (`/r/...`)  
3. **전화 잔여 큐** — 알림톡으로도 안 된 곳만 스크립트+결과 기록  

이 세 단계가 “마감 독촉 OS”이고, 자동수집 올인과 겹치지 않습니다.
