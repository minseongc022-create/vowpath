# 수임체크(SuimCheck) 아웃리치 리드 — 소형 세무·기장 사무소

**작성일:** 2026-07-26  
**대상:** 독립·소형 세무·기장 사무소 (대형 다점포 법인 우선 제외)  
**수집 기준:** 각 사무소 **공식 웹사이트(또는 공식 블로그)에 공개된** 이메일·웹문의·카카오 채널만 기재. 추정·합성 이메일 없음.

---

## 아웃리치 지침

1. **이메일 또는 웹폼만** 사용합니다. **전화 콜드콜 금지.**
2. 공개된 카카오 채널이 있으면 채널 메시지(광고성 문구 최소화)로 대체 가능.
3. 1회 짧은 소개 → 관심 시에만 데모/요금 안내. 압박·반복 발송 금지.
4. 개인정보·수임처 데이터는 요청하지 않습니다. 제품 소개·데모 링크만.
5. 회신이 없거나 거절이면 즉시 중단합니다.

**제품 한 줄:** 수임체크는 소형 세무·기장 사무소의 **수임처 자료 요청·독촉을 알림톡·현황판으로 자동화**하는 SaaS입니다. (전표·신고 대행 아님)

**데모/사이트:** https://suimcheck.kr · 문의: hello@suimcheck.kr

## 바로 보낼 한국어 메일 템플릿

### A. 첫 연락 (이메일 / 웹폼 공통)

**제목:** 수임처 자료 요청, 전화·카톡 대신 알림톡으로 — 수임체크 소개

```
안녕하세요, {사무소명} 담당자님.

수임체크(SuimCheck)입니다. 소형 세무·기장 사무소에서
마감 때마다 수임처에 ‘자료 아직이세요?’를 전화·개인 카톡으로
돌리는 시간을 줄이도록, 정보성 알림톡 요청과 제출 현황판을
자동화하는 도구입니다.

· 수임처 CSV 등록 → 마감일 기준 1·2차 요청
· 미제출만 재발송, 제출 현황 한눈에
· 전표·신고 대행이 아니라 ‘자료 추심’만 담당

데모(가입 즉시 현황판 체험): https://suimcheck.kr
요금: 스타터 월 7.9만(수임 30곳)부터

관심 있으시면 회신만 주셔도 됩니다. 원치 않으시면
‘관심 없음’이라고만 남겨 주시면 더 이상 연락드리지 않겠습니다.

수임체크 드림
hello@suimcheck.kr
```

### B. 부가세·종소세 마감 전 짧은 버전

**제목:** 마감 전 수임처 독촉, 알림톡으로 돌릴 수 있습니다

```
안녕하세요, {사무소명}입니다.

부가세·종소세 마감 전, 수임처별 자료 요청을
전화 대신 스케줄·알림톡으로 돌리는 수임체크를 짧게 소개드립니다.

데모: https://suimcheck.kr
문의: hello@suimcheck.kr

필요 없으시면 ‘거절’만 회신해 주세요. 감사합니다.
```

### C. 웹폼용 (이름·연락처·내용 필드가 있을 때)

```
[이름] 수임체크 담당
[연락처] hello@suimcheck.kr (회신용 이메일 우선)
[내용]
소형 세무·기장 사무소용 ‘수임처 자료 요청 자동화’ 도구(수임체크) 소개드립니다.
전화·개인 카톡 독촉 대신 정보성 알림톡과 현황판으로 마감을 맞춥니다.
데모: https://suimcheck.kr / 회신: hello@suimcheck.kr
원치 않으시면 회신 없이 무시하셔도 됩니다.
```
