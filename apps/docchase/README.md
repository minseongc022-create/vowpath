# 수임체크 (SuimCheck)

소형 세무·기장 사무소용 **마감 독촉 OS** — 알림톡 → 원탭 회신 → 전화 잔여 큐.

> Effiroad와 분리된 독립 사이트 (`apps/docchase`).

## 차별점 (클로브 ≠ 비슷함)

| | 수임체크 | 자동수집 올인 |
|--|----------|----------------|
| JTBD | 안 낸 곳 쫓기 | 자료 가져오기·기장 |
| 수임처 | 카톡 링크만 | 앱/연동 부담 가능 |
| 루프 | 알림톡→원탭→전화큐 | 수집 중심 |

## 플랜 (스티커 저가 · 구독 고마진)

| 플랜 | 월 | 거래처 | 알림톡 | 비고 |
|------|-----|--------|--------|------|
| 라이트 | 29,000 | 30 | 100 | 제출·원탭·전화큐 |
| 스탠다드 | 59,000 | 80 | 300 | 자동·일괄·CSV |
| 프로 | 99,000 | 200 | 800 | 맞춤·담당 5 |

알림톡 원가≈13원 → 포함팩 COGS 수천 원, 구독이 본마진. 초과 29~39원.

## 알림톡 연동

`docs/ALIMTALK_SETUP.md` · `.env.example` (솔라피)

## 로컬

```bash
cd apps/docchase
npm install
cp .env.example .env.local   # 솔라피 키(선택)
npm run dev                  # :3001
```

| 경로 | 역할 |
|------|------|
| `/dashboard` | 오늘 독촉 |
| `/dashboard/calls` | 전화 잔여 큐 |
| `/s/[token]` | 제출 |
| `/r/[token]` | 원탭 회신 |
| `/api/alimtalk/*` | 솔라피 발송 |
