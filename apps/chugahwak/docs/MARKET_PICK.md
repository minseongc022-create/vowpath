**질문:** 상위호환(클로브급) 없이, 돈은 흐르는데 도구가 엉망인 곳 → 대장 자리

---

## 1. 클로브 가격 (비교 기준)

| 제품 | 가격 |
|------|------|
| 클로브AI / 클로브커넥트 | **평생 무료** (금융 수수료로 수익) |
| 위하고T | 연 ~96만 원대 ERP |
| 추가확정 | 월 3.9~9.9만 (합의 OS만) |

→ **수집·기장 올인**은 클로브가 무료로 깔아 둠. 같은 카테고리로 가면 패배.

---

## 2. 전 세계 스캔 → 왜 ‘추가공사 합의’인가

### 필터
1. 이미 돈이 움직임 (분쟁·미수·놓친 청구)
2. 기존 앱/웹 불평이 큼
3. **무료·올인 상위호환이 카테고리를 잠그지 않음**
4. 초기 ~20만 원으로 MVP
5. 월 ~1,000만 경로 (100~150곳 × 6~10만)

### 탈락
| 후보 | 탈락 이유 |
|------|-----------|
| 세무 자동수집 | 클로브 **무료** 상위호환 |
| 월세 임대관리 | 집사·렌티 **무료** |
| 미용 예약 마켓 | Fresha/Booksy/네이버 예약 전쟁 |
| 풀스택 ERP | 이디스·얼마에요·위하고 — 무겁고 경쟁 |
| AI 전화 접수 | 경쟁 9/10 |

### 당선: **Change Order / 추가공사 합의 OS**

| 증거 | 내용 |
|------|------|
| 미국 | Jobber에 **정식 CO 워크플로 없음** — GC 리뷰 핵심 불만. Buildertrend는 비쌈 |
| 한국 | 추가공사대금 = **서면·명시 합의** 없으면 청구 깨짐 (판례·법률 콘텐츠 다수). 실무는 카톡·구두 |
| 경쟁 | 적산 ERP·오늘의집 멤버십은 있어도 **‘승인 링크 한 장’ 전용 대장**은 비어 있음 |
| 돈 | 놓친 CO 50만 원 = 구독 1년 ROI. 분쟁 자체가 현금 |

해외 레퍼런스: Opsite/Jobkore의 “change order with e-sign, no login” 쐐기를 **한국 인테리어·개보수**에 맞춤.

---

## 3. 제품 쐐기

**알림톡/카톡 → 승인 링크 → 금액·품목·공기연장 → 승인/거절 → 변경대장**

하지 않음: 견적 적산, 자재 DB, 자동수집, 스케줄 디스패치.
